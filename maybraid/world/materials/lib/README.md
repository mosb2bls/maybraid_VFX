# Maybraid World Materials

The composed [`MaterialRef`](../../material-ref) library for Maybraid World.

Domain shaders stay in their crates. This crate is the global recipe-name table: furniture, character, urban (including `doric_column`), muzzle flame, energy (`laser_hex`, `laser_pulse`, `laser_tail`), then vegetation and Standard.

```text
cargo test -p world-materials
```
