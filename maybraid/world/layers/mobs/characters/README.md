# Characters

Character model, rigs, motion, shaders, items, persist, and playgrounds for the mobs layer.

The generated mob-character crate is [`generated/`](generated/) (`mob-characters`). Lower-order crates are named by what they do.

## Layout

| Path | Crate |
| --- | --- |
| [`lib/`](lib/) | **`characters`** |
| [`generated/`](generated/) | **`mob-characters`** |
| [`rigs/`](rigs/) | **`character-rigs`** |
| [`animations/`](animations/) | **`character-animations`** |
| [`motion/`](motion/) | **`character-motion`** |
| [`ragdoll/`](ragdoll/) | **`character-ragdoll`** |
| [`shaders/`](shaders/) | **`character-shaders`** |
| [`items/`](items/) | **`character-items`** |
| [`persist/`](persist/) | **`character-persist`** |
| [`model-user/`](model-user/) | **`character-model-user`** |
| [`inventory-user/`](inventory-user/) | **`character-inventory-user`** |
| [`playground/`](playground/) | **`characters-playground`** |
Character UI menus live under [`maybraid/menu/`](../../../../menu/).
