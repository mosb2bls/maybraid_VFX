# `sbs-trees`

**Stalk and ball-stick trees**: integrates **`sdf-common`**, **`sbs-geometry`**, and **`vegetation-components`** into the construction API targeted by [RFC-183 §3.1](https://github.com/ramate-io/maybraid/tree/main/rfc/rfc-000-000-183-chico-vegetation#31-stalk-and-ball-stick-trees).

Primary tracking issue: [#186 — RFC-183 4.1: Ball-stick Primitive API](https://github.com/ramate-io/maybraid/issues/186). Parent epic: [#185](https://github.com/ramate-io/maybraid/issues/185).

To port another construction onto Storybook-style merge + `unit_from_num` (and the matching grove flatten), see [CONTRIBUTING.md](CONTRIBUTING.md).
